This project includes a data scraping and fine-tuning pipeline for training
StarCoder2 on Revit API and Dynamo Python scripting content.

Third-party data sources used by the scrapers (Dynamo Forum, Stack Overflow,
GitHub) are subject to their own terms of service. The scraped dataset
produced by this pipeline is not redistributed as part of this repository.
